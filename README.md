# stw1.github.io

Personal site for Stephen T. Wong: https://stw1.github.io (GitHub Pages publishes `master` on every push).

Plain static HTML/CSS/JS, no build step. `index.html` is the content, `styles.css` the design, `main.js` the small page behaviour (scroll reveals, footer year), `images/` the portrait and photos.

## What the page covers (as of 2026-11-20)
One page with these sections, in order: hero, **About**, **What I Do** (focus areas), **Approach** (strategic initiatives), **Projects & Apps** (all apps, games and tools, stat "20+ built"), **Contact**.
- The site is about Stephen as a person, not an employer; there is no job title in the copy or metadata.
- Contact buttons go to LinkedIn. **No public email address is published**; don't add one.
- Removed on purpose: Education section, the World of Warcraft stat, the old Projects section and its images.
